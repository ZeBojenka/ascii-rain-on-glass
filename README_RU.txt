ASCII RAIN ON GLASS — JavaScript версия

Это самостоятельное браузерное приложение: никаких Python, pygame, numpy, npm или внешних библиотек не требуется.

Локальный запуск:
1. Распакуйте архив.
2. Откройте index.html двойным щелчком в браузере.

Для GitHub + Vercel:
- Загрузите index.html в корень репозитория GitHub.
- Импортируйте репозиторий в Vercel как статический проект.
- Build Command оставьте пустой; Output Directory — `.` (корень проекта).
- После деплоя откройте выданную Vercel ссылку.

Управление:
- Пробел — пауза/продолжить
- ↑ / ↓ — яркость
- ← / → — интенсивность дождя
- L — молния
- H — показать/скрыть подсказку
- +/- — детализация
- Мышь или палец: провести по стеклу, чтобы протереть его
- Кнопки «Пауза» и «Молния» доступны на сенсорных экранах.

Примечание: это перенос визуальной идеи на Canvas, а не построчная конвертация Python. Реализованы ASCII-рендеринг, ночной город, боке, движущиеся огни машин, капли, мокрые дорожки, блики, молнии и управление.

Исправление мерцания: исходная сцена теперь рисуется на отдельном скрытом Canvas, а видимый Canvas показывает только ASCII-кадр. Это предотвращает промежуточное отображение обычной картинки.
